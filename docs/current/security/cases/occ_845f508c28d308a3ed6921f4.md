# GPU3D transient validation omits the polygon mode and vertex-count relationship

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_845f508c28d308a3ed6921f4` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** The post-fix GPU transient validator accepts VertexNumInPoly=3 independently of PolygonMode, and PolygonMode is restored later without validation. In triangle mode, the next submission writes slot 3 and increments the count to 4, misses the equality-only reset at 3, and the following submission writes TempVertexBuffer[4].
- **Attack path:** A state restores triangle mode with VertexNumInPoly=3. Two subsequent vertex commands make the second command write beyond TempVertexBuffer.
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Static cross-field state-transition proof and prior-occurrence comparison; Vertex count validated without polygon mode; The accepted count is not related to the later-restored polygon mode. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Normal BEGIN commands mask PolygonMode and reset the counter. The current helper rejects an initially out-of-range count, but the accepted inconsistent pair transitions into one.
- **Limitations:** No separate item was recorded in the sealed finding.
- **Recommended correction:** Restore and validate PolygonMode before committing transient state. Enforce mode-specific valid VertexNumInPoly values and guard the TempVertexBuffer index before every write; reject impossible transitions.
