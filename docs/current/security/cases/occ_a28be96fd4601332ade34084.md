# Persistent native threads leak JNI local references across SAF and camera callbacks

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_a28be96fd4601332ade34084` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `app`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Native-to-Java bridges create JNI local references on manually attached threads that remain alive across repeated calls, but do not delete those locals or establish bounded local frames.
- **Attack path:** Three or more local references accumulate per URI open.
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Independent static JNI lifetime trace from native SaveManager thread through repeated provider-backed opens; Each SAF open allocates three local references and never deletes them; There is no DeleteLocalRef or PushLocalFrame/PopLocalFrame on success or failure. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Save writes are debounced and failed retries use bounded backoff. Those rate controls slow accumulation but do not bound opens across the worker lifetime.
- **Limitations:** No runtime exhaustion threshold or crash was measured on a device. No CheckJNI/ART local-table capacity measurement or installed-device exhaustion test was executed.
- **Recommended correction:** Adopt one scoped JNI ownership policy for every native-thread-to-Java bridge: use PushLocalFrame/PopLocalFrame or RAII DeleteLocalRef cleanup on all success, failure, exception, and allocation-error paths. Fix UriFileHandler's path/mode/class locals and all camera start/stop/capture class locals; optionally cache deliberately owned global class references and method IDs.
