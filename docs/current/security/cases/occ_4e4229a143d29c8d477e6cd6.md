# Cheat XML import does not bound internal entity expansion or parsed text

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED`.

- **Identity and status:** `occ_4e4229a143d29c8d477e6cd6` · scan `4c41e000-6ba0-4453-aaa7-3cdbec542687` · severity `low` · layer `app`. Technical disposition from CSV: CORRECTED. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** The cheat importer parses a user-selected XML document with the Android default SAX configuration and does not disable DOCTYPE/internal entities or impose input, expanded-character, nesting, or field limits.
- **Attack path:** Selected cheat XML URI -&gt; default Android SAX parser -&gt; internal entity expansion -&gt; unbounded 'characters()' appends -&gt; foreground worker memory/CPU exhaustion
- **Evidence and proof level:** **static** in the sealed finding (`status not specified`): Independent offline application-source trace with platform-behavior reconciliation; The import flow accepts a user-selected XML document; The attacker must supply a document that the user explicitly chooses through the Storage Access Framework. Disposition evidence: **recorded dynamic post-fix checks**; pre-fix evidence remains static unless the report records an explicit RED — DTD/entity and oversize text tests pass. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** Android's default Expat path does not resolve external general entities, external parameter entities, or external DTDs, so no local-file disclosure or SSRF route was established. Direct recursive entity references are parser errors.
- **Limitations:** No Android runtime matrix or entity-amplification proof of concept was executed. Exact parser expansion thresholds vary by Android release.
- **Recommended correction:** Configure the SAX factory/reader to reject DOCTYPE and disable external general entities, external parameter entities, and external DTD loading. Independently cap source bytes, expanded characters, nesting, per-field length, and aggregate games/cheats, and convert limit violations into a normal failed WorkManager result.
