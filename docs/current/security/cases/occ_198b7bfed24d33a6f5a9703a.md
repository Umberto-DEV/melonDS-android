# Provider-controlled ROM names can escape, collide with, and overwrite SRAM and savestate targets

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_198b7bfed24d33a6f5a9703a` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `app`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** For an ad-hoc granted ROM, the selected content provider controls 'DocumentFile.name' while the app has no parent tree and falls back to a file-backed 'externalFilesDir/saves' root. 'SramProvider' changes only the final extension and passes the resulting string to 'findFile' or 'createFile' without rejecting separators, dot segments, or collisions.
- **Attack path:** selected malicious content URI -&gt; provider display name -&gt; ad-hoc ROM with null parent -&gt; local raw save/state roots -&gt; unvalidated child creation -&gt; native SRAM or savestate writes
- **Evidence and proof level:** **static** in the sealed finding (`status not specified`): Static source trace plus offline bytecode inspection of the resolved DocumentFile 1.1.0 dependency; Unknown granted content URIs become ad-hoc ROMs without a parent tree; A selected unknown content URI is imported with 'parentUri = null'; its display name is supplied by the selected provider. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** 'RawDocumentFile.createFile' uses 'createNewFile', so an already-existing traversal target is not overwritten through the creation branch.
- **Limitations:** The AndroidX implementation was verified from the offline dependency cache rather than vendored source. No Android provider or filesystem reproduction was executed.
- **Recommended correction:** Derive SRAM names from a stable digest or validated leaf basename rather than provider display names. Reject '/', '\', dot segments, empty/reserved names and collisions not explicitly bound to the selected ROM. For file-backed roots, resolve canonically and require the candidate parent to equal the canonical save root before creating or opening it.
