# The sized rcheevos deserializer still overreads malformed RCHV chunks

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_374991baf934127ee85e4c58` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `app`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** The Android caller now passes the real RCHV buffer size and caps the outer section, but the bundled sized deserializer validates only a chunk's declared end before dispatch. A short 'DONE' chunk reaches a fixed 16-byte digest 'memcmp', and other readers consume 32-bit values, without enforcing the chunk or actual-buffer remainder.
- **Attack path:** save-state document -&gt; bounded RCHV vector -&gt; declared chunk size -&gt; DONE handler -&gt; unchecked 16-byte memcmp
- **Evidence and proof level:** **static** in the sealed finding (`reportable`): Independent static source trace and prior-occurrence reconciliation; Android supplies the actual bounded RCHV vector; The previous call-site issue is corrected: an exact vector size and explicit 16 MiB/section cap reach the sized API. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Outer MELN framing, a 16 MiB cap and the sized API call are correctly implemented. Android backup rollback occurs only after a parser failure and cannot prevent the already-performed native overread.
- **Limitations:** No malformed RCHV state was executed under ASan or HWASan.
- **Recommended correction:** Carry both actual-buffer end and current-chunk end through every reader. Before dispatch, validate mandatory payload minima, including exactly 16 bytes for DONE; reject offset arithmetic overflow, and make each 32-bit or variable-size reader fail before accessing beyond either boundary.
