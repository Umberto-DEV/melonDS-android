# Crafted savestates control native callback, FIFO, audio-buffer, and table indices

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED`.

- **Identity and status:** `occ_2993485bc81b37540bda66df` · scan `4c41e000-6ba0-4453-aaa7-3cdbec542687` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Android restores live native scheduler, FIFO/DynamicFIFO, IPC, and SPU metadata from a selected savestate without re-establishing representation invariants. A crafted state can place an out-of-range FuncID into the three-entry scheduler callback table; restore generic or IPC FIFO positions outside their backing arrays; or restore SPU playback/capture positions and ADPCM indices used before normal masking or clamping.
- **Attack path:** Serialized FuncID flows to evt.Funcs[FuncID], whose result is invoked.
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Semantic reconciliation of already-validated Standard findings; no repository inspection or runtime execution.; Function ID and scheduling state restored; The file controls the array index, call parameter, due time, and whether the event is active. Disposition evidence: **recorded dynamic post-fix checks**; pre-fix evidence remains static unless the report records an explicit RED — semantic invariant tests and full sanitizer build pass. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** Normal ScheduleEvent calls use registered program-selected IDs. Registration assertions constrain registration count, not deserialized IDs.
- **Limitations:** Potential code execution is inferred from native memory/control-flow corruption, not dynamically reproduced. No exploit or device reproduction was executed.
- **Recommended correction:** Deserialize scheduler, every FIFO/DynamicFIFO, IPC, and SPU state into temporary objects.
