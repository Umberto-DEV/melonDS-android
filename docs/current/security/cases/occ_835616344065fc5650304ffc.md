# Restored GPU VRAM mapping masks select outside the native bank tables

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_835616344065fc5650304ffc` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** GPU savestates restore VRAM mapping masks and immediately convert single-bit masks to native bank pointers. GetUniqueBankPtr accepts any power-of-two mask, so a serialized bit above bank eight makes __builtin_ctz produce an index outside the nine-entry VRAM and VRAMMask arrays.
- **Attack path:** A savestate supplies a mapping mask such as bit 9 in GPUG. Loading calls GetUniqueBankPtr before a domain check, reads beyond VRAM/VRAMMask, and forms an invalid host pointer.
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Static deserialization and bit-domain proof; High single-bit mask indexes past nine VRAM banks; The power-of-two test does not require num &lt; 9 before indexing the bank tables. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Normal register mapping code constructs masks from valid bank numbers. The helper rejects zero and multi-bit masks for its unique-pointer fast path, but not an out-of-domain single bit.
- **Limitations:** No crafted state was executed under ASan.
- **Recommended correction:** Validate every restored mapping against its exact legal bank mask before committing or forming pointers. Require num &lt; 9 inside GetUniqueBankPtr and all dirty-tracking/copy consumers as defense in depth. Dedup-0034 refinement: reject every bit outside '0x1ff' before reconstruction and enforce 'bank &lt; 9' in both pointer helpers.
