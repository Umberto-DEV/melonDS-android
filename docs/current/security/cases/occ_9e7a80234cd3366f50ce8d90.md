# DSi DSP HLE pipe descriptors escape mapped host memory

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED`.

- **Identity and status:** `occ_9e7a80234cd3366f50ce8d90` · scan `4c41e000-6ba0-4453-aaa7-3cdbec542687` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Android enables DSi DSP HLE. The emulated guest can modify pipe descriptors in DSP-visible NWRAM, including buffer address, length, and read/write offsets. 'GetDataMemPointer()' explicitly returns a pointer valid only within one 32 KiB page, but 'ReadPipe()' and 'WritePipe()' add the descriptor offsets and access memory before wrapping or checking the page/allocation span.
- **Attack path:** guest MBK/NWRAM pipe descriptor -&gt; raw page pointer -&gt; unchecked ring offset -&gt; 'pipebuf[...]'
- **Evidence and proof level:** **static** in the sealed finding (`validated`): static guest-memory-to-host-pointer trace; Android enables DSP HLE in DSi mode; The final 'true' enables DSP HLE in the Android DSi arguments, making these implementations product-reachable. Disposition evidence: **recorded dynamic post-fix checks**; pre-fix evidence remains static unless the report records an explicit RED — pipe/page/pointer/odd-length tests pass. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** HLE startup requires recognized DSP microcode, but that identifies a program and does not authenticate subsequent guest-writable descriptor memory. Requires a recognized HLE microcode and DSi configuration.
- **Limitations:** No DSi ROM PoC or ASan run was produced. No DSi proof of concept or sanitizer run was executed.
- **Recommended correction:** Treat DSP pipe descriptors as untrusted. Validate that the mapped page exists, buffer length is nonzero/even, base plus the full ring lies inside one valid mapped allocation, and read/write offsets are below the ring length before every access. Prefer bounded emulated-memory accessors over raw host pointers.
