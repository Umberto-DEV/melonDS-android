# An external app can substitute an unrelated cached ROM during an exported launch

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_3f076c55d71a70958a33220f` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `app`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** The exported emulator activity correctly accepts only a caller-granted 'Intent.data' content URI, but repository lookup can replace that URI with an existing cached 'Rom' based solely on provider metadata.
- **Attack path:** external granted URI -&gt; 'LaunchArgs' -&gt; provider name/length -&gt; cached 'Rom' heuristic -&gt; cached ROM URI/config/save -&gt; native launch
- **Evidence and proof level:** **static** in the sealed finding (`validated`): static source trace from exported Intent to operational ROM/save URI; The emulator activity is exported for launch actions; Another installed application can address the exported launch contract. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Serialized 'Rom', legacy path, and arbitrary URI extras are no longer accepted; this is a different post-admission route. The caller must provide a readable granted content URI and a suitable cached ROM must already exist.
- **Limitations:** No second Android app, malicious 'DocumentsProvider', Binder grant test, or save mutation was executed. Static offline validation; no malicious provider or save mutation was exercised.
- **Recommended correction:** Keep the caller-authorized URI as the operational document. Reuse cached display/configuration data only after a trustworthy identity match tied to the same authority/document, and remove size-only matching from exported launch resolution. Additional dedup-0016 remediation detail: For externally authorized launches, preserve an origin flag and load only the exact granted URI.
