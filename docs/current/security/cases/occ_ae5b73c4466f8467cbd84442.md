# GPU2D savestates restore unchecked display-FIFO pointers

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_ae5b73c4466f8467cbd84442` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** 'GPU2D::Unit::DoSavestate' restores 32-bit display-FIFO read and write cursors directly beside a 16-entry array and performs no semantic validation. The next guest FIFO write indexes 'DispFIFO[write]' and '[write+1]' before masking; FIFO display sampling similarly reads 'DispFIFO[read]' before masking. A crafted Android savestate can therefore cause controlled native out-of-bounds reads/writes immediately after load.
- **Attack path:** Cursor is committed without range/alignment validation.
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Static savestate-to-live-GPU dataflow trace.; FIFO pointers are restored without range checks; No load-only validation ensures the pointers are within the 16-entry FIFO. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Normal reset initializes zero. Normal runtime masks after each access.
- **Limitations:** No crafted state was executed under ASan. No crafted state was executed with sanitizers.
- **Recommended correction:** Deserialize the GPU2D FIFO cursors into temporaries and reject the state before commit unless the read cursor is below 16 and the paired write cursor is even and at most 14. Set 'Savestate::Error', leave the live object unchanged, and apply checked/masked indexing before every sample or 16/32-bit write rather than after dereference.
