# Null PATH extra crashes the exported singleTask launch path

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED`.

- **Identity and status:** `occ_d540d679331dce207e3adb60` · scan `4c41e000-6ba0-4453-aaa7-3cdbec542687` · severity `low` · layer `app`. Technical disposition from CSV: CORRECTED. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** A local app can deliver a Bundle containing the PATH key with a null string to a running exported EmulatorActivity. The onNewIntent parser treats key presence as non-nullness and force-unwraps getString, causing a KotlinNullPointerException before invalid arguments are ignored.
- **Attack path:** external Intent Bundle -&gt; 'containsKey(KEY_PATH)' -&gt; 'getString(KEY_PATH)' -&gt; '!!'
- **Evidence and proof level:** **static** in the sealed finding (`status not specified`): Static source validation with sibling-extra review; PATH key presence is force-unwrapped as a string; Bundle key presence does not guarantee a non-null string value. Disposition evidence: **recorded dynamic post-fix checks**; pre-fix evidence remains static unless the report records an explicit RED — null/malformed launch tests pass. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** Normal app-generated intents use non-null paths. Cold-start parsing does not force-unwrap PATH.
- **Limitations:** No runtime reproduction was performed. Android background-activity-launch policy may limit when another app can surface the activity.
- **Recommended correction:** Replace the branch with extras.getString(KEY_PATH)?.let(::RomPath) and apply nullable type-safe decoding to every externally supplied extra.
- **Disposition, patch and before/after:** Treat absent/null PATH as invalid input rather than dereferencing it **Before:** null extra crashed singleTask path **After:** null/malformed launch tests pass Recorded integration pair: [app a77ccaaa](https://github.com/Umberto-DEV/melonDS-android/commit/a77ccaaac5ca99f4ac1893b1dfb9b41326f75811); [core 65952aec](https://github.com/Umberto-DEV/melonDS-android-lib/commit/65952aec868bedd2dc33151ed850804e3e13df05).
