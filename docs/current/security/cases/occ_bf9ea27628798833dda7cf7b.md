# Malformed cartridge images cause native out-of-bounds reads and secure-area writes

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED`.

- **Identity and status:** `occ_bf9ea27628798833dda7cf7b` · scan `4c41e000-6ba0-4453-aaa7-3cdbec542687` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Android can pass short or internally inconsistent NDS, DSi, and GBA cartridge images into native parsing without a complete validation boundary. Managed preflight can accept an NDS image as short as 0x160 bytes (padded only to 0x200), and an explicit 512-byte construction reaches the unconditional 4,096-byte NDSHeader copy, reading 3,584 bytes beyond that allocation.
- **Attack path:** attacker ROM URI -&gt; native exact-length allocation -&gt; next-power-of-two buffer -&gt; fixed 4096-byte memcpy
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Semantic reconciliation of already-validated Standard findings; no repository inspection or runtime execution.; Independent offline static source trace; Independent offline static source trace with boundary construction; NDS direct boot trusts ARM ranges; No ROMLength comparison precedes the native read. Disposition evidence: **recorded dynamic post-fix checks**; pre-fix evidence remains static unless the report records an explicit RED — CartridgeImageBounds ASan/UBSan controls pass. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** Kotlin metadata checks cover only some ordinary NDS fields and do not establish immutable native spans, DSi ranges, or rounded reads. The sink writes into emulated RAM; the confirmed host violation is the native source overread.
- **Limitations:** The finding does not claim a controlled native write or demonstrated code execution. No runtime sanitizer reproduction or data exfiltration path was established.
- **Recommended correction:** Make NDS and GBA ParseROM the mandatory validation boundary. Before padding, copying, construction, or insertion, require the full format-specific minimum against the original content length; align the Kotlin preflight and require complete fixed-region reads.
