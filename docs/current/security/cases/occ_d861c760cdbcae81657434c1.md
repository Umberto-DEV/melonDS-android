# A direct ROM URI can force a one-gigabyte native allocation

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED`.

- **Identity and status:** `occ_d861c760cdbcae81657434c1` · scan `4c41e000-6ba0-4453-aaa7-3cdbec542687` · severity `medium` · layer `app`. Technical disposition from CSV: CORRECTED. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Another installed app can grant the exported emulator activity a large seekable ROM URI, and normal user-selected or archive-extracted ROM launch reaches the same loader. 'MelonInstance' accepts lengths through 1 GiB and first allocates and reads the entire file.
- **Attack path:** attacker-controlled file length -&gt; whole-file allocation -&gt; next-power-of-two length -&gt; second native allocation -&gt; process termination
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Static size and allocation trace from exported URI to native core; Exported launch forwards granted ROM URI to native loading; Another installed app can explicitly invoke this component with a URI from its own provider and a read grant. Disposition evidence: **recorded dynamic post-fix checks**; pre-fix evidence remains static unless the report records an explicit RED — 512 MiB NDS and 32 MiB GBA caps pass. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** Lengths above 1 GiB are rejected. Power-of-two input avoids the second buffer.
- **Limitations:** No device-specific OOM threshold was measured. No device-specific heap budget or live OOM reproduction was measured.
- **Recommended correction:** Set format-derived ROM maxima and a conservative Android process allocation budget before reading. Avoid duplicating the ROM solely for power-of-two addressing, or allocate once into a checked final capacity. Remove 'noexcept' from allocating helpers, contain allocation/JNI failures, and validate provider length against bytes actually read.
