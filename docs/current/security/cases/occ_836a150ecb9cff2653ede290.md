# Live SPU timer-reload writes can index before interpolation tables

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_836a150ecb9cff2653ede290` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Emulated software can change TimerReload on an already-running PCM channel without normalizing its current Timer. If the reload becomes greater than Timer, the interpolation calculation wraps in unsigned arithmetic, converts to a negative signed sample position, bypasses the upper-only clamp, and indexes native cosine, cubic, or Gaussian tables before their start.
- **Attack path:** guest SPU MMIO reload write -&gt; TimerReload &gt; live Timer -&gt; unsigned wrap -&gt; negative samplepos -&gt; interpolation table index
- **Evidence and proof level:** **static** in the sealed finding (`validated`): static arithmetic and dual-route source trace; Guest register changes reload on a live channel; Emulated software can write the channel timer-reload register while the channel remains enabled. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Start initializes Timer from TimerReload on initial key-on, but later guest reload writes do not re-run Start. Linear interpolation does not index these lookup tables; cosine, cubic, and Gaussian do.
- **Limitations:** No malicious ROM or sanitizer reproduction was executed.
- **Recommended correction:** Make SPUChannel::Run compute interpolation position with checked, widened arithmetic and clamp the final index to 0..255 before every table lookup, because Timer &lt; TimerReload can arise from legitimate guest register changes. Separately validate restored counters for representational and consumer-specific bounds.
