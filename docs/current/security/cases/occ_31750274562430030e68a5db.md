# Retail NAND cartridge savestates retain unchecked staging cursors and addresses

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_31750274562430030e68a5db` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** The prior cartridge-savestate fix validates transfer-array fields and immutable SRAM length, but 'CartRetailNAND::DoSavestate()' still restores 'SRAMBase', 'SRAMWindow', 'SRAMAddr', and 'SRAMWritePos' without semantic bounds. A crafted compatible state can make the next NAND write command underflow the remaining staging-buffer length or commit through an underflowed SRAM offset, causing native out-of-bounds writes.
- **Attack path:** savestate NAND fields -&gt; successful CartRetailNAND restoration -&gt; ROM command 0x81/0x82 -&gt; unsigned underflow -&gt; memcpy outside staging buffer or SRAM allocation
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Independent static validation of polymorphic cartridge restoration and subsequent write/commit commands; Base state restores the command address but validates only allocation length; The immutable allocation length is protected, but the active address is accepted without requiring it inside that allocation. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Normal cartridge commands reset and increment the cursor within capacity. The serialized SRAM length must match the active allocation.
- **Limitations:** Static validation only. No exact heap/stack corruption layout was executed.
- **Recommended correction:** Deserialize all NAND-cartridge state into temporaries. Reject before commit unless SRAMBase matches the immutable ROM-derived base, SRAMWindow and SRAMAddr form overflow-safe spans inside the active allocation, SRAMWritePos is at most 0x800, and every pending 0x800-byte staging commit fits completely.
