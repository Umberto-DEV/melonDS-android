# Failed save-writability checks leak native provider descriptors

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_1db371734a02d73a8775b1cc` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `low` · layer `app`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Both NDS and GBA loaders open a save document for reading before calling CheckFileWritable. That helper opens and closes separate probe handles. If append access is rejected, the loader returns without closing its original read FILE. Because UriFileHandler detaches the ParcelFileDescriptor and transfers it to fdopen, each failed launch retains a native/provider descriptor until process exit.
- **Attack path:** A selected save provider permits read opens but rejects append; each failed NDS/GBA launch leaks the original read handle; repeated attempts exhaust process descriptors.
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Offline ownership and early-return analysis.; NDS early return skips CloseFile; The cleanup is only on the success path. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Success paths close the handle. Probe handles are themselves closed.
- **Limitations:** Descriptor exhaustion count/device limit not measured.
- **Recommended correction:** Use an RAII wrapper for Platform::FileHandle in MelonInstance so all returns close automatically. At minimum close sramFile/saveFile before the failed writeability return, or perform the writeability probe before retaining the read handle.
