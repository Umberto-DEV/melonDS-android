# Unrestricted tag pushes can initiate Google Play production deployment

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_REPOSITORY_EXTERNAL_CONTROL_UNVERIFIED`.

- **Identity and status:** `occ_7fddae3d4a0847da222da76c` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `high` · layer `app`. Repository control applied; production environment absent from the GitHub API results; tag protection unverified. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** The same generic non-nightly tag trigger starts a Play Store job with no actor, repository, environment, reviewer, or protected-ref gate. The job checks out the tagged source, signs its Play production APK, and invokes the Play service account on 'track: production' without draft status.
- **Attack path:** tag push -&gt; checkout tag-selected source -&gt; materialize Play signing credentials -&gt; build signed APK -&gt; service-account production upload
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Independent workflow inventory followed by source tracing and sibling-control comparison; Generic tags trigger the Play production job; Every tag except the nightly tag activates the workflow with no production-release authorization predicate. Disposition evidence: **mixed**: repository checker executed; external control unverified — Repository integrity policy passes; GitHub API follow-up found production environments absent; tag protection remained unverified. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** Pinned Actions and distribution checks reduce dependency substitution risk but do not authorize the tag creator. External GitHub and Play policies may add controls not present in source.
- **Limitations:** Repository and Play Console policies were not queried by explicit offline constraint.
- **Subsequent configuration check:** The GitHub API read after the scan lists no environments in the fork and only `copilot` upstream; `production-playstore` is not configured. The repository gate prevents the fork from running the job; the upstream path requires the specified actor and manual dispatch. Tag protection and Play Console policy remain unverified; [Details](../SECOND-CAMPAIGN.md).
- **Recommended correction:** Remove direct production upload from the generic tag workflow. Build without release secrets, attest the artifact digest, and require a protected production environment with reviewers before a minimal promotion job signs and uploads that digest. Enforce protected release tags, explicit least-privilege permissions, and draft/staged rollout until approval.
