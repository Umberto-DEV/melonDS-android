# Malformed DSi NAND exports can disclose uninitialized stack bytes

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_4c6c667123e2f9c495f39cbe` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Require every FatFs read and host write in NAND export to complete exactly before publishing bytes. ExportFile trusts the FAT directory size, ignores f_read status and nread, and writes the full requested block from an uninitialized/reused stack buffer, so a malformed cluster chain can place native stack remnants in the Android-selected output file.
- **Attack path:** nand.bin FAT entry -&gt; ExportTitleData -&gt; f_read failure/short read -&gt; uninitialized buf -&gt; FileWrite to SAF
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Independent Android-to-core export trace plus direct FatFs short-read semantics review; Export writes full blocks regardless of FatFs result/count; buf is not initialized and neither the source result/count nor destination result is inspected before blocklen bytes are exported and success is returned. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Structurally valid healthy FAT files normally return full blocks. Disclosure requires an explicit export operation after the malicious NAND is configured.
- **Limitations:** No malformed NAND fixture was constructed to measure leaked bytes or destination behavior. No malformed NAND image was mounted or exported dynamically.
- **Recommended correction:** Require f_read == FR_OK and nread == blocklen before writing. Require FileWrite to report one complete element and propagate f_close/CloseFile failures. Abort on any mismatch, close both handles, and delete or truncate the partial destination through the platform abstraction. Zero-initialize buf only as defense in depth, not as a substitute for exact-count validation.
