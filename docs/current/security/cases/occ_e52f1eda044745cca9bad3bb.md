# Restored DSi DSP timestamps can trap the emulator in a zero-progress catch-up loop

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_e52f1eda044745cca9bad3bb` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** DSi savestates restore the ARM9 and DSP 64-bit timestamps independently without a cross-clock invariant. When an enabled DSP is exactly '2^32' cycles behind, 'DSPCatchUp()' sees bit 32 set but passes only the zero low word to 'Run(0)'; the timestamp does not advance, the backlog is unchanged, and the native loop never terminates.
- **Attack path:** savestate ARM9/DSP timestamps and enable flags -&gt; successful load -&gt; DSP callback/register access -&gt; low-word truncation -&gt; repeated Run(0)
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Independent static arithmetic proof plus restoration and trigger-path review; Core time and registered events are restored separately; Scheduler function identity is checked, but no relationship to the DSP's later timestamp is enforced. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** A disabled DSP takes an early path that synchronizes its timestamp. A DSP timestamp at or ahead of ARM9 returns before the loop.
- **Limitations:** Static validation only; the authorized scan did not hang the app. Exact UI recovery behavior after a native emulator-thread hang was not tested.
- **Recommended correction:** Validate restored clock relationships and replace the loop with positive bounded chunks, for example 'chunk = min(backlog, UINT32_MAX)' and reject or cap unreasonable total catch-up work. Assert that each iteration decreases backlog and enforce an iteration/work budget. Dedup-0031 refinement: Validate restored DSPTimestamp against ARM9Timestamp and reject impossible or excessive deltas.
