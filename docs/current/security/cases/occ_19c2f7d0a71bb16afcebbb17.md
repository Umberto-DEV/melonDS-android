# Cyclic document-provider trees can repeatedly crash ROM library scanning

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_19c2f7d0a71bb16afcebbb17` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `app`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Traverse untrusted document trees iteratively with stable visited identities and strict depth/entry budgets. The ROM scanner recursively follows every provider child marked as a directory without remembering document IDs or URIs, so a granted provider can return itself or an ancestor until StackOverflowError; the persisted directory then retriggers the denial of service on later loads and rescans.
- **Attack path:** persisted tree URI -&gt; DocumentFile.listFiles -&gt; provider child directory -&gt; recursive call
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Independent provider-boundary and recursion trace; First ROM observation launches a full scan; The persisted search directories are traversed when the library is first loaded, not only in a one-off picker operation. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** scanMutex prevents concurrent scans but does not ensure termination. DocumentFile may internally catch provider exceptions, but this path relies on successful cyclic responses and no exception.
- **Limitations:** No fake DocumentsProvider reproduction was executed in this static campaign. No malicious DocumentsProvider fixture was run.
- **Recommended correction:** Replace recursion with an iterative queue/stack. Track visited nodes using provider authority plus stable DocumentsContract document ID (and a normalized URI fallback), skip repeated identities, and enforce conservative maximum depth, total directories, total entries and scan duration/cancellation checks.
