# Restored SPU scheduler parameters can write beyond blip audio buffers

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_681a4f167a153dbb72619581` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Savestate loading validates scheduler callback identity but not SchedEvent.Param, and restores SPU MixInterval without bounds. A crafted legitimate Event_SPU can pass an oversized cycle count to SPU::Mix; the code calls blip_add_delta before flushing, and blip-buf uses that time to write a 16-value kernel beyond its fixed 512-sample allocation.
- **Attack path:** serialized SchedEvent.Param / MixInterval -&gt; valid Event_SPU callback -&gt; BlipTimer -&gt; blip_add_delta pointer -&gt; 16 native writes
- **Evidence and proof level:** **static** in the sealed finding (`validated`): static source trace and buffer-time calculation; Scheduler Param restored but not semantically bounded; Validation checks callback registration, not whether Param is safe for the selected event function. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Callback identity and scheduler mask are now validated. blip_add_delta contains an assertion, but assertions are not a release safety boundary and an enabled assertion yields process termination.
- **Limitations:** No crafted state or ASan reproduction was executed.
- **Recommended correction:** Validate per-event Param domains during savestate load, restrict SPU MixInterval to supported values, and reject or flush before any blip delta whose converted time can exceed buffer capacity. Keep a non-assert runtime guard inside the blip wrapper.
