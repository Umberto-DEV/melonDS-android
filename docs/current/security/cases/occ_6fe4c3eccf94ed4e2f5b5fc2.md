# A name-only NAND candidate can make guided setup consume storage until provider EOF

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_6fe4c3eccf94ed4e2f5b5fc2` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `app`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Guided BIOS setup scans the user-selected directory and automatically chooses any loose file named 'nand.bin'. NAND validation reads only one byte, after which 'copyInto()' streams the source into a new document until EOF without checking a declared length, counting copied bytes, enforcing a NAND-size allowlist/quota, or checking available space.
- **Attack path:** Selected tree -&gt; loose name match -&gt; one-byte validation -&gt; EOF-bounded copy -&gt; canonical or partial document
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Offline source trace of Android SAF discovery, validation, copy, publication, and cleanup; A loose name alone selects the NAND candidate; After the user selects a folder, any loose case-insensitive 'nand.bin' is automatically selected; no size or content classification is performed. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** The user explicitly selects the parent directory. The buffer bounds per-iteration heap use.
- **Limitations:** No malicious provider or low-space device was executed under the offline read-only constraint. The review is static and offline; no storage-exhaustion input was generated.
- **Recommended correction:** Define and enforce a conservative accepted NAND-image size policy before copying, reject known declared lengths outside it, and independently count streamed bytes so unknown-length or length-drifting providers are aborted before the quota.
