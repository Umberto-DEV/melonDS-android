# Large achievement sets exhaust JNI references and pin Java strings

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_a32f5bdeefb1bbbc68fd7eaf` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `medium` · layer `app`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** RetroAchievements data is converted to arrays whose sizes and strings come from the remote response. Native mapping loops create achievement, leaderboard and string local references for every item without deleting them or using local frames, while the achievement and rich-presence paths release UTF characters only when JNI reports that a copy was made.
- **Attack path:** Remote DTO collections -&gt; Java arrays -&gt; JNI per-item object/string refs -&gt; no local-ref deletion and skipped releases
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Offline JNI ownership and loop-growth analysis; All remote items are converted for native setup; Remote set sizes and strings determine the Java arrays passed to native achievement setup. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** Local references are normally reclaimed when the native method returns. A sufficiently large loop can exhaust resources before return; string release is still contractually required.
- **Limitations:** ART-specific exhaustion threshold was not measured.
- **Recommended correction:** Cap arrays and strings before JNI, use 'PushLocalFrame'/'PopLocalFrame' or delete every per-item local reference in each iteration, release every non-null 'GetStringUTFChars()' result unconditionally, and abort safely on pending JNI exceptions or null acquisitions.
