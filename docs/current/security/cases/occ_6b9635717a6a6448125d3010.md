# Guest DNS parsing can read beyond the frame and return stale native bytes

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED`.

- **Identity and status:** `occ_6b9635717a6a6448125d3010` · scan `4c41e000-6ba0-4453-aaa7-3cdbec542687` · severity `medium` · layer `core`. Technical disposition from CSV: CORRECTED. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Android always installs Net_Slirp, whose custom DNS handler reads fixed Ethernet/IP/UDP/DNS offsets and advances through guest-controlled labels without tying every access to the actual frame length.
- **Attack path:** guest Wi-Fi frame -&gt; 'WifiAP' or 'DSi_NWifi' LAN buffer -&gt; Android 'Net::SendPacket()' -&gt; 'Net_Slirp::SendPacket()' -&gt; 'HandleDNSFrame()' unchecked label cursor
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Semantic reconciliation of already-validated Standard findings; no repository inspection or runtime execution.; Android always installs Slirp driver; This parser is selected by the Android frontend. Disposition evidence: **recorded dynamic post-fix checks**; pre-fix evidence remains static unless the report records an explicit RED — truncated frame/label tests return no answer. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** len is capped at 2048, but no minimum or per-field DNS bound is established here. The 255-byte domain output check protects destination stack size, not source packet reads.
- **Limitations:** No crash payload was executed. No reliable memory disclosure channel was established.
- **Recommended correction:** Before any fixed access, validate complete Ethernet, IPv4, UDP, and DNS headers and cross-check IPv4 header length, IP total length, UDP length, and DNS body length against the actual frame. Parse names with a cursor/end pair that checks every length byte, label body, terminator, and QTYPE/QCLASS trailer; reject unsupported compression and labels over 63 bytes.
