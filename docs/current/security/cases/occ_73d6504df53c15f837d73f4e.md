# A crafted DSi ROM can obtain uninitialized host stack bytes through failed SD or NAND reads

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED_SECOND_SCAN`.

- **Identity and status:** `occ_73d6504df53c15f837d73f4e` · scan `ab26b107-97dd-4557-9c4b-2942e5df879d` · severity `high` · layer `core`. Technical disposition from CSV: CORRECTED_SECOND_SCAN. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** 'DSi_MMCStorage::ReadBlock()' allocates an uninitialized 512-byte stack buffer, ignores failed or short reads from both FAT-backed SD storage and direct internal NAND I/O, and unconditionally returns the requested span through the emulated FIFO. A crafted DSi title can issue an aligned read beyond a short backing image so no bytes are written while native stack residue is exposed to the guest.
- **Attack path:** guest SD/MMC read address -&gt; FAT or NAND backing read returns zero/short -&gt; untouched stack array -&gt; DataRX -&gt; guest FIFO
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Independent static trace through Android stdio backing implementation and DSi NAND response path; Guest supplies the NAND read address; For byte-addressed NAND, the guest parameter is used directly and can select an aligned offset beyond the backing file. Disposition evidence: **recorded post-fix class/suite tests, without an individual dynamic reproduction of the trigger** — Focused regression plus final host/JVM/NDK/ART checks recorded in the second-campaign report. This card is supported by source analysis unless it cites a specific RED/GREEN result; aggregate final checks are not counted as an individual finding GREEN.
- **Counterevidence:** The FATStorage helper zeroes some short-read suffixes, but internal NAND uses direct unchecked FileRead. Some libc/compiler configurations may incidentally leave predictable or zero-like stack data; there is no source-level guarantee.
- **Limitations:** Static validation only. The disclosure contents depend on stack reuse.
- **Recommended correction:** Zero-initialize the full sector buffer as defense in depth, reject out-of-range addresses, require exact successful reads from both FATStorage and direct NAND I/O before DataRX, and return a deterministic emulated error or defined zero data on failure.
