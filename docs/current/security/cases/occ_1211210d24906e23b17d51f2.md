# A malformed settings backup can prevent every later app launch

[Security index](../README.md) · [Disposition register](../FINDINGS.csv)

**Canonical disposition:** `CORRECTED`.

- **Identity and status:** `occ_1211210d24906e23b17d51f2` · scan `4c41e000-6ba0-4453-aaa7-3cdbec542687` · severity `low` · layer `app`. Technical disposition from CSV: CORRECTED. The Security UI state may remain **Open**; it is separate from the technical disposition.
- **Summary:** Manual settings restore applies JSON values according to attacker-controlled runtime type rather than an allowlisted preference schema. Concrete valid backups can write 'last_version' as Boolean although startup migration calls 'getLong', or write 'theme' as Boolean although settings initialization calls 'getString'.
- **Attack path:** settings.json -&gt; untyped SharedPreferences write -&gt; startup getLong
- **Evidence and proof level:** **static** in the sealed finding (`validated`): Static restore-to-next-start trace with concrete JSON payload; The target key is known to require Long; 'last_version' has an explicit type requirement but is neither excluded nor universally enforced during restore. Disposition evidence: **recorded dynamic post-fix checks**; pre-fix evidence remains static unless the report records an explicit RED — mixed/poisoned settings tests pass. No dynamic RED is inferred unless the report records it explicitly.
- **Counterevidence:** User explicitly selects/restores the backup. Credential and SAF directory exclusions work.
- **Limitations:** The exact Android exception/crash screen was not reproduced. The exception was not executed on device.
- **Recommended correction:** Restore only allowlisted user-facing keys through a versioned schema that defines each expected type, range, and enum domain. Exclude internal migration/update bookkeeping such as 'last_version', bound input size, validate the entire document before applying any edit, ignore unknown keys, commit transactionally, and make startup recover safely from legacy type mismatches.
